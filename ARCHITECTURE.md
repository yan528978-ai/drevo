# Древо — архитектура (сборка поверх готовых компонентов)

## Принцип

Не изобретать инфраструктуру заново. Собирать систему из проверенных open-source блоков, конфигурируя их под цикл и принципы Древа. Свой код — только там, где есть реальная специфика (правила анализа под конкретные задачи).

## Маппинг слоёв на компоненты

| Слой Древа | Назначение | Готовый компонент |
|---|---|---|
| **Корни** | Сбор данных | `feedparser`, `requests` — RSS/API; Haystack или LangChain document loaders — веб/документы; при необходимости — knowledge-graph инструменты (напр. graphify) |
| **Ствол** | Принципы, состояние | `Pydantic` — схема состояния; стандартные Python-логирование и конфиги, без кастомного кода |
| **Ветви** | Анализ | Агент-фреймворк — выбор по сложности:<br>• **Smolagents** — один агент, самый быстрый старт<br>• **LangGraph** — если нужны ветвления и сложная логика решений<br>• **CrewAI** — несколько специализированных агентов по разным ветвям |
| **Листья / Действие** | Цикл работы | `ooda-subagents` (github.com/al3rez/ooda-subagents) — готовый набор агентов под цикл Observe→Orient→Decide→Act, подключается как git submodule |
| **Плоды / Обратная связь** | Результаты, накопление опыта | Knowledge graph — следующий цикл Наблюдения подхватывает, что сработало в прошлом |

## Практический план запуска

1. Взять **Smolagents** или **ooda-subagents** как готовый скелет — уже реализует нужный цикл
2. Подключить один источник данных через готовый loader (не писать свой парсер)
3. Использовать **Pydantic** для схемы состояния вместо самодельной
4. Писать свой код только для специфики анализа под задачи Древа

## Почему это снижает риск

Ключевая проблема, из-за которой застряла первая попытка (с ChatGPT) — не в идее, а в том, что автор концепции не является Python-разработчиком, а реализация с нуля требует именно этого навыка. Сборка из готовых блоков превращает задачу «написать инфраструктуру» в задачу «сконфигурировать существующее» — это ближе к работе интегратора, чем исследователя, и заметно снижает порог входа для будущего технического исполнителя.
